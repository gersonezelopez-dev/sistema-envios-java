# ****Proyecto****

## **Sistema de gestión de envío**

**Descripción** 

Aplicación de consola desarrollada en Java que permite registrar 
envíos nacionales e internacionales y calcular el costo final de 
cada envío según su peso, distancia o cargos adicionales.

**Objetivo**

Desarrollar un programa aplicando los principales conceptos de 
Programación Orientada a Objetos (POO), utilizando clases para 
representar y calcular diferentes tipos de envíos.

**Temas del Proyecto**

* Clases y objetos.
* Atributos y métodos.
* Encapsulamiento.
* Constructores.
* Herencia.
* Sobrecarga de métodos.
* Sobrescritura de métodos.
* Polimorfismo.
* Validación de datos.

## ****Instrucciones para ejecutar el programa****

Se presenta las siguientes instrucciones de como ejecutar el proyecto son breves y consisas de como poder operarlo.

1. Abrir el proyecto en IntelliJ IDEA.
2. Verificar que las clases se encuentren dentro de la carpeta src (Importante).
3. Abrir la clase Main.java (Es para ejecutar o copilar código desde esta ventana).
4. Ejecutar el método main.
5. Seleccionar una opción del menú:
6. Registrar envío nacional.
7. Registrar envío internacional.
8. Salir.
9. Ingresar los datos solicitados por el programa.

# **Resultado esperado**

El programa permite registrar un envío nacional o internacional y muestra 
un resumen con los datos ingresados, el costo base, los cargos adicionales 
y el costo final.

-Para un envío nacional de 5 kg y 120 km de distancia:

* Costo base: Q50.00
* Cargo por distancia: Q60.00
* Costo final: Q110.00

-Para un envío internacional de 3 kg:

* Costo base: Q30.00
* Cargo internacional: Q75.00
* Recargo del 12%: Q3.60
* Costo final: Q108.60
